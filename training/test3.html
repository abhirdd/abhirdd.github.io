Deep Test: window.open Empty URL / location=no

Internal testing only. File ini untuk memvalidasi perilaku browser internal tim kamu, khususnya apakah window.open() dengan parameter lama seperti location=no masih bisa menyembunyikan address bar atau menghasilkan URL kosong tanpa indikator keamanan.
Catatan penting: Browser modern umumnya akan menormalisasi URL kosong ke about:blank, menampilkan URL sumber, atau memblokir perilaku berisiko. Jika browser internal kamu membiarkan URL benar-benar kosong tanpa security indicator, itu perlu direview sebagai potensi UI spoofing / address bar manipulation.

3. Checklist Manual Deep

Gunakan checklist ini saat popup terbuka. Fokusnya bukan cuma “URL kosong”, tapi apakah user masih bisa membedakan UI browser asli dan konten web.

Item Expected Aman Berisiko Actual Status
Address bar terlihat? Ya, tetap terlihat meski halaman meminta location=no. Address bar hilang / disembunyikan oleh web content.
URL kosong? Untuk web umum: sebaiknya tidak kosong. Normal ke about:blank atau tunjukkan origin/sumber. URL kosong tanpa indikator keamanan jelas, sehingga user tidak tahu halaman berasal dari mana.
Parameter location=no diabaikan? Ya, browser mengabaikan parameter deprecated tersebut. Browser menuruti location=no dan menyembunyikan address bar.
Security indicator jelas? Ada tanda jelas bahwa ini konten web, bukan UI browser asli. Halaman bisa tampak seperti UI browser asli.
Tab/title tidak menyesatkan? Title tidak menyerupai label sistem browser. Title/ikon membuat user mengira itu UI browser.
Bisa ditutup / ESC berfungsi? User bisa keluar atau menutup popup dengan jelas. Popup sulit ditutup atau tetap menempel di atas UI.

4. Interpretasi Status

Status Arti Tindakan
EMPTY_URL_ALLOWED Browser mengizinkan popup.location.href benar-benar kosong. Review keamanan. Untuk web content tidak trusted, ini berisiko. Jika ini mode internal/app khusus, pastikan ada indikator browser yang jelas.
ABOUT_BLANK_NORMALIZED Browser menormalisasi URL kosong menjadi about:blank. Umumnya lebih aman daripada URL kosong. Tetap cek apakah address bar terlihat dan location=no diabaikan.
INHERITED_CURRENT_URL Popup mewarisi URL halaman induk. Cek apakah ini sesuai desain browser. Bisa berisiko jika user mengira popup berasal dari domain berbeda.
BLOCKED Popup diblokir popup blocker / policy browser. Untuk test internal, izinkan popup untuk domain test atau jalankan variant satu per satu.
CROSS_ORIGIN_OR_BLOCKED Script tidak bisa membaca popup.location.href. Bisa normal jika popup cross-origin/sandboxed. Validasi manual address bar.
WRITE_DENIED Popup terbuka tetapi halaman tidak bisa menulis konten. Cek policy browser, sandbox, atau origin popup.
Rekomendasi untuk tim browser internal: Jika kebutuhan produk adalah “window app tanpa address bar”, jangan implementasikan lewat web page yang memanggil window.open(location=no). Gunakan mode native/trusted browser, misalnya app window/kiosk mode, dengan kebijakan eksplisit: origin jelas, security indicator, title tidak bisa meniru UI browser, dan user tahu sedang berada di mode khusus.
