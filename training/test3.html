browser
Realita: tidak ada trik universal yang membuat toolbar asli menampilkan example.com di atas konten attacker pada browser terpatch. Surface modern di bawah (picker geometry, top-layer, view-transition, fullscreen) adalah kelas bug versi-spesifik. Hasil “simulasi / by-design” bukan temuan; hanya anomali pada toolbar asli di build belum-patch yang valid.

Native Select Picker Geometry

idle

Kelas CVE-2026-14077: anchor rect picker tidak di-clip ke viewport sehingga popup native bisa menutupi toolbar. Di browser terpatch, popup terpotong di area halaman.

Aman / patchedPopup picker ter-clip di viewport, tidak menutupi toolbar asli.
Finding (build lama)Popup native muncul di atas toolbar asli dan menutupi omnibox.
Menunggu
Jalankan dan amati popup terhadap toolbar asli.

Popover + Anchor Negative Offset

idle

Top-layer (Popover API + CSS anchor) dengan margin negatif. Elemen top-layer tetap di dalam viewport halaman; ia tidak bisa menutupi toolbar asli. Bila terlihat “di atas halaman”, itu hanya menggambar dalam halaman = simulasi.

Aman / by-designPopover ter-clip di viewport; chrome browser tak tersentuh.
FindingHanya bila elemen benar-benar menutupi toolbar asli (tidak mungkin in-page pada browser sehat).
Menunggu
Jalankan untuk melihat batas top-layer.

Dialog showModal Negative Inset

idle

<dialog> modal + backdrop berada di top-layer.Inset/transform negatif menguji apakah dialog bisa lolos ke chrome. Pada browser sehat, dialog tetap di viewport.

Aman / by-designDialog + backdrop hanya menutup halaman.
FindingDialog/backdrop menelan toolbar asli (versi-spesifik).
Menunggu
Jalankan untuk menguji inset negatif.

View Transition Snapshot vs URL

idle

Ubah URL (hash) lalu tahan callback transisi agar snapshot lama tampil lebih lama. Ini jendela animasi by-design yang singkat, bukan spoof toolbar asli. Di file:// pakai hash; di http(s) bisa path.

Aman / by-designJendela snapshot singkat dan konsisten dengan commit URL.
FindingMismatch URL vs konten yang bisa diperpanjang sewenang-wenang di toolbar asli.
Menunggu
Jalankan untuk mengamati jendela snapshot.

Fullscreen Fake Chrome

simulasi

Halaman bebas menggambar “browser frame” palsu. Ini simulasi dan bukan temuan — browser sehat menampilkan indikator fullscreen sendiri. Ini menjelaskan kenapa screenshot “omnibox example.com + marker” yang digambar halaman tidak valid.

AmanBrowser menampilkan indikator fullscreen sendiri; fake bar jelas berlabel LAB.
Bukan findingFake chrome in-page tidak pernah menjadi temuan spoof toolbar asli.
Simulasi
Fake chrome in-page = by-design, bukan temuan.
Gunakan hanya pada browser/lab milik sendiri. Untuk temuan nyata: uji build belum-patch/fork lama, rekam layar penuh termasuk toolbar asli, catat versi + timing, dan bandingkan dengan stable terbaru. Jangan meniru halaman login atau mengumpulkan kredensial.
