🧠 Mengapa sebelumnya gagal?
Browser menolak karena BlobURLStore memvalidasi pasangan (origin, uuid). String palsu ditolak secara silent oleh download manager.

💡 Strategi "Mind-Blowing" Baru:
Kita tidak hanya menggunakan <a> click. Kita akan menyuntikkan URL palsu ke 4 Vektor API Browser berbeda (<a>, window.open, <iframe> src, dan location.href). Tujuannya: Memancing UI Leakage. Mungkin download-nya gagal, tapi apakah Address Bar iframe, Tab Title, atau Chrome Error Page secara tidak sengaja menampilkan "trusteddomain.com"? Itulah celah UI Spoofing yang kita cari.

🚀 Jalankan Multi-Vector Spoof Probe

Mint UUID asli dari opaque origin, lalu buat 4 variasi URL palsu. Setiap variasi akan diserang ke 4 API browser berbeda secara bersamaan. Amati log dan UI browser Anda.
