📋 Test Case Execution

TC-001: IDN Homograph Attack (Cyrillic)

Menguji apakah browser menampilkan Punycode atau warning saat domain menggunakan karakter Cyrillic yang mirip Latin (misal: а vs a).

TC-002: Credential Bypass via '@' Symbol

Menguji parsing URL. Browser seharusnya menyorot evil.com sebagai domain utama, bukan abhirdd.github.io.

TC-003: Special Character Injection

Menguji respons browser terhadap Null Byte (%00) dan Tab Character (%09) dalam URL.

TC-004: Right-to-Left (RTL) Override

Menguji apakah browser menetralkan karakter U+202E (RTL Override) yang dapat membalik tampilan URL secara visual.

TC-010: Fullscreen UI Redressing (Critical)

Mensimulasikan serangan phishing yang menyembunyikan address bar asli browser menggunakan Fullscreen API dan merender UI palsu.
